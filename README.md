## 🚀 Featured Projects

### 1. DevGuard AI
*AI-Powered Code Debugging & Vulnerability Auditing Concept (Hackathon)*
- **Problem**: Manual code reviews and vulnerability triage are time-consuming during rapid sprint cycles.
- **Solution**: Automated LLM-driven code auditing engine that analyzes repositories, detects vulnerabilities, and suggests context-aware fixes.
- **Tech Stack**: Python, FastAPI, AI / LLM APIs, Prompt Engineering, Git APIs

### 2. PocketOps AI
*Autonomous Mobile AI Phone Operator Concept*
- **Problem**: Multi-step mobile operations require tedious manual interaction across several applications.
- **Solution**: Conversational agent system that parses natural-language user directives into structured action plans and executes device tasks.
- **Tech Stack**: Android SDK, Kotlin, LLM APIs, Agent Workflows, REST APIs

### 3. SafeRoute AI
*AI-Driven Risk-Aware Navigation Engine*
- **Problem**: Traditional map services optimize solely for travel duration without accounting for safety indicators or dynamic risk factors.
- **Solution**: Safety-weighted routing engine combining backend database queries with hazard scoring to calculate secure transit paths.
- **Tech Stack**: Python, FastAPI, PostgreSQL, Map APIs, Docker

### 4. ReelTune
*Flutter Music Streaming & Background Audio Application*
- **Problem**: Lightweight background music playback requires robust lifecycle, audio session, and buffering management.
- **Solution**: Cross-platform audio player with background playback controllers, playlist queues, and clean fluid UI.
- **Tech Stack**: Flutter, Dart, Audio Services, REST APIs, Mobile UI

### 5. Philately Passport Karnataka
*Location-Based Tourism & Philatelic Heritage Concept*
- **Problem**: Cultural and philatelic heritage sites lack interactive digital touchpoints for younger generations.
- **Solution**: Location-aware exploration app offering collectible digital postal stamps for historical postal landmarks across Karnataka.
- **Tech Stack**: Flutter, Dart, Firebase, Geolocation APIs

## 💻 Portfolio Tech Stack

The portfolio website itself is built to be fast, lightweight, and dependency-free:

- **Markup**: Semantic HTML5 with accessibility attributes (`aria-*`)
- **Styling**: Modern CSS3 (CSS Grid, Flexbox, Custom Properties, Glassmorphism, Dark Developer Theme)
- **Scripting**: Vanilla JavaScript (ES6+, `IntersectionObserver` for ScrollSpy, Clipboard API, Mobile Drawer Toggle)
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)
- **Zero Build Steps**: Runs directly in any modern browser without heavy node modules or bundlers.

## ⚡ Getting Started Locally

No package installation or build steps are required. You can run the portfolio locally using any static web server:

### Option 1: Using Python (Recommended)
```bash
# Navigate to the project directory
cd portfolio

# Start a local HTTP server
python -m http.server 8080
```
Then open your browser at `http://localhost:8080`.

### Option 2: Using Node.js `serve` / `npx`
```bash
npx serve .
```

### Option 3: Using VS Code Live Server
1. Open the project folder in **Visual Studio Code**.
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.
